Git & GitHub

Mengenal pengertian, perbedaan, serta sejarah Git dan GitHub dalam pengembangan perangkat lunak.

1. Pengertian Git dan GitHub

Git dan GitHub merupakan dua hal yang sering digunakan dalam pengembangan perangkat lunak. Keduanya membantu programmer mengelola kode program, mencatat perubahan, serta bekerja sama dalam sebuah proyek. Meskipun sering digunakan bersamaan, Git dan GitHub bukanlah hal yang sama.

GIT

Git

Git adalah sistem pengontrol versi terdistribusi (Distributed Version Control System/DVCS) yang digunakan untuk melacak perubahan pada file, terutama kode program.

GH

GitHub

GitHub adalah platform berbasis internet yang menyediakan tempat untuk menyimpan repositori Git, berkolaborasi, dan mengelola proyek perangkat lunak.

2. Sejarah Git

Git dibuat oleh Linus Torvalds, yang juga dikenal sebagai pencipta kernel Linux.

Sebelum Git dibuat, pengembangan Linux menggunakan sistem pengontrol versi bernama BitKeeper. Pada tahun 2005, terjadi perubahan dalam penggunaan BitKeeper untuk pengembangan Linux sehingga diperlukan sistem pengontrol versi baru.


Linus Torvalds kemudian membuat Git dengan tujuan menyediakan sistem yang cepat, terdistribusi, dan mampu menangani pengembangan proyek besar seperti kernel Linux.

Perkembangan Git

2005

Awal pengembangan Git

Linus Torvalds membuat Git untuk mendukung pengembangan kernel Linux.

2005

Rilis awal Git

Git mulai digunakan sebagai sistem pengontrol versi untuk pengembangan Linux.

Saat ini

Digunakan secara luas

Git digunakan dalam berbagai proyek perangkat lunak, mulai dari tugas kuliah hingga pengembangan aplikasi berskala besar.

3. Sejarah GitHub

GitHub didirikan pada tahun 2008 oleh Tom Preston-Werner, Chris Wanstrath, P. J. Hyett, dan Scott Chacon.

Platform ini dikembangkan untuk memudahkan programmer menyimpan proyek Git secara online serta berkolaborasi dengan programmer lain.


GitHub kemudian berkembang menjadi salah satu platform penting dalam pengembangan perangkat lunak, baik untuk proyek pribadi, proyek open source, maupun pengembangan aplikasi perusahaan.

Perkembangan GitHub

2008

GitHub diluncurkan

GitHub mulai menyediakan layanan hosting repositori Git dan kolaborasi pengembang.

2018

Diakuisisi Microsoft

Microsoft mengakuisisi GitHub untuk memperluas pengembangan dan layanan kolaborasi perangkat lunak.

Saat ini

Platform pengembangan kolaboratif

GitHub menyediakan fitur repositori, Pull Request, Issues, Actions, dan berbagai layanan pengembangan lainnya.
